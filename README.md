# 墨案 X · 番茄小说兼容与精简项目

> **项目主目标：适配真实的番茄小说服务，而不是另写一个普通 TXT/EPUB 阅读器。**

## 必须保留的核心功能

- 番茄小说账号登录
- 原账号书架与阅读进度同步
- 番茄小说在线正文阅读
- 番茄小说原生在线听书（不是本地 TTS 替代）
- 适合墨案 InkPad X 的低动画、快速翻页、黑白高对比界面

## 设备约束

- 设备：墨案 InkPad X 候选型号（固件 `MAS_EPD101_L61M101_V35_220624`），实际型号仍需真机复核
- 参考硬件：Android 8.1、Cortex-A7 ARM 32 位、2GB RAM
- 新版番茄小说 7.3.5.32 用户上传的 APK 仅含 ARM64 原生库，不能直接把机器码改成 ARM32
- 已发现番茄小说官方签名的 ARM32 版本 **6.5.9.32 / armeabi-v7a / Android 5.0+**，但其 2026 年登录、书架和在线听书可用性 **尚未通过真机测试**

## 实施次序

1. 获取原始 32 位 APK 并校验来源和签名，先确认它确实支持真实番茄服务
2. 在墨案设备上检查安装、登录、同步、正文和在线听书，并收集实际错误与性能反馈
3. 基于能工作的官方客户端，优先采用无须修改签名的显示/刷新/性能优化
4. 如需修改 APK，只在互操作性与合法授权范围内进行，并评估重签名导致的登录、更新、安全和服务兼容性风险
5. 只有官方接口授权且功能实测通过时，才宣称可独立重构登录/书架/听书

## 现有 v0.3 的准确定位

GitHub Actions 现有构建生成的 v0.3 **只是独立本地阅读技术原型**，支持 TXT/EPUB、本地音频和系统 TTS，**不是番茄小说精简客户端，不具备番茄官方服务**。请勿将其作为目标产品交付。

本仓库为用户设备个人兼容性研究，不公开上传或分发番茄小说的第三方专有 APK、反编译代码、账号令牌或内部接口密钥。
