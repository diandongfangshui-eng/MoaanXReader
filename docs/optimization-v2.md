# 墨案 X / 番茄小说 6.5.9.32：原版保签名性能优化 v2

**真实验收前提**：用户确认 32 位官方原版在墨案 X 能正常启动、登录、同步书架、在线阅读、播放番茄官方在线听书。任何优化不得破坏这四项功能。

## 为什么先不做“删广告模块后重新签名的 APK”

经检查原包为 ARM32 `armeabi-v7a`，约 84.44MiB、18 DEX、113 个 ARM32 .so、约 15570 文件；Manifest 含 560 Activity、152 Service，并设置 `largeHeap=true`。这些数据表明包复杂，但**不能直接推断运行时 RAM 占用或哪个 SDK 导致卡顿**。

删除其字节码、so 或资源会影响原版签名完整性。没有官方签名密钥，不能承诺重新签名后保留原版登录及同步等服务。故目前阶段**不重新打包番茄的专有 APK，不公开上传 APK、私有令牌或专有代码**。

## 已实现、可回退的优化试验

通过电脑 ADB 在运行 Android 8.1 的墨案 X 上：

1. `check`：检查设备 ABI/安卓版本/番茄包版本以及动画设置。
2. `start`：重置目标 app 的 Android 绘图统计（不清除数据）。
3. 在原版番茄中固定执行书架滚动 30 秒、翻页 30 次、官方听书 2 分钟。
4. `capture before`：采集目标包的 PSS 内存、CPU 与绘图帧统计。
5. `optimize`：保存原值，将 Android 三项**设备全局**动画缩放设为 0（仅这三项写入）。
6. 在墨案自带设置里试用应用级文字快速刷新；番茄阅读设置中关闭翻页效果（仅当选项实际存在）。
7. 再做同样操作，`capture after`。
8. `restore`：恢复第一次保存的动画设置。

可选 `startup`：需要明确输入 YES，先停止再启动番茄做冷启动计时，会中断正在播放的有声书，但**不清除账号数据**。

在无电脑时，可在 Android 开发者选项手动关闭三项动画缩放，并记录原值便于恢复。

### 不应冒险执行的“优化”

- 禁止番茄后台运行、强制省电或禁用其网络权限：可能损害书架同步和在线听书。
- 清空应用数据：会丢失登录状态和可能尚未同步的本地数据。
- 按组件名字 `pm disable-user` 广告、播放器等 Activity/Service：它们可能共用启动依赖，甚至导致启动崩溃。
- 全局修改分辨率或 DPI：可能使触控与弹窗错位。
- 删除 .so、DEX、资源后重新签名，并宣称原账号及官方服务仍完全可用。

**限制**：三项系统动画只控制 Android 系统级过渡；番茄内部动画、WebView、墨水屏硬件刷新和网络加载仍可能卡顿。PSS 及 gfxinfo 才能初步区分瓶颈；gfxinfo 不直接度量 E Ink 面板物理刷新耗时。

设备信息报告不包含账号口令，但仍应私人传送，不公开提交未检查的日志。
